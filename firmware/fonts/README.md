# Montserrat pt-BR

Fonte Montserrat do Google Fonts, licença SIL Open Font License 1.1 (OFL.txt).
Origem: https://github.com/google/fonts/tree/main/ofl/montserrat
O arquivo TTF original acompanha o projeto para regeneração.
SHA256 TTF: 0f7b311b2f3279e4eef9b2f968bcdbab6e28f4daeb1f049f4f278a902bcd82f7

Conversor oficial LVGL lv_font_conv 1.5.3 (npm), executado com Node.js 22.20.0.
C gerado nos tamanhos 20/28, 4 bpp, sem compressão, ASCII + Latin-1; cada C
inclui as opções de regeneração no cabeçalho. UTF-8 permanece ativado. Fontes
builtin LVGL são fallback apenas para ícones. Fontes C prontas são compiladas,
sem necessidade de Node/conversor no build normal ESP-IDF ou CI.
