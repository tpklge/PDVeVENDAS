# v0.3.0 — administração e autenticação (candidata)

Branch release/v0.3.0-authentication. Firmware 0.3.0, servidor compatível API 0.2.0.
Entregues primeiro boot, configuração persistente criptografada, administrador
local, Wi-Fi C6/SDIO, NTP, TLS com bundle/hostname, health/compatibilidade, login,
troca obrigatória, sessão, perfis/permissões, refresh e logout.

Desbloqueio admin-local após cada reinício aprovado pelo usuário. Senha local e
chave não são armazenadas em texto puro; tokens em memória interna. Sem eFuses
automáticas. Provisionamento do admin ERP pelo CLI já implantado no servidor.
Diagnóstico preservado; não há módulos comerciais ou cache/fila nesta entrega.

Autoteste criptográfico no dispositivo antes de provisionar. Pinos e versões
do rádio conforme exemplo oficial M5Stack; firmware C6 existente ainda precisa
ser comprovado compatível no equipamento do usuário.

Roteiro: docs/authentication.md. Compilação/testes e hashes serão registrados
após verificação. Validação física da etapa pendente; main/tag preservam 0.2.0.

11 testes locais da API/registro privado aprovados; 104 caracteres com glifos
