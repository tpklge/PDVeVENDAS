# 0.8.0 — Estoque (implementação iniciada)

A correção do fluxo de vendas foi entregue separadamente no OTA 0.7.1,
compatível com o servidor 0.7.0 já instalado.

## Base implementada na API

- GET /api/v1/inventory: pesquisa, saldo, mínimo, filtro de estoque baixo e páginas por revisão.
- GET /api/v1/inventory/{id}: saldo, status e versão do produto.
- GET /api/v1/inventory/{id}/movements: histórico de saldo antes/depois, quantidade, operador, motivo e venda vinculada.
- POST /api/v1/inventory/adjustments: entrada, saída ou ajuste por saldo contado;
  exige inventory.adjust, versão atual, justificativa e chave de idempotência.
- Inventory.read permite consultas sem revelar preços de custo/venda.
- Quantidades decimais, saldo nunca negativo, mesma transação para saldo, movimento,
  auditoria, revisão e resultado de repetição. Bloqueios são compartilhados com as vendas.
- Migração incremental 005_inventory preserva movimentos existentes e acrescenta
  apenas a tabela de resultados idempotentes de movimentação.

Entrada/saída usam quantity positiva; ajuste usa target_quantity maior ou igual a zero.
Reenvio com mesma chave/corpo retorna o movimento original; corpo diferente é recusado.
Produto inativo recusa novos movimentos e mantém consultas/histórico.
