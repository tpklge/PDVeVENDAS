# 0.7.1 — Fechamento de venda

Usuário confirmou vendas funcionando em 0.7.0. A revisão de interface usa:
Revisar e cobrar → conferir total, pagamentos e troco → Confirmar pagamento e concluir.
Após confirmação da API, a tela mostra Venda concluída, com o comprovante não fiscal.
Cancelamento mostra Venda cancelada. O botão de confirmar ocupa largura suficiente
para a legenda completa. A indicação de conclusão continua dependendo da resposta
do servidor; uma tentativa incerta mantém o fluxo de recuperação.

Instalar TAB5_ERP-v0.7.1-app-OTA.bin pelo launcher existente.
Esta revisão de interface funciona com a API 0.7.0 instalada: não exige migração,
reinicialização de usuários nem alteração do servidor.

A interface não confirma automaticamente Pix/cartões e não emite documento fiscal.
