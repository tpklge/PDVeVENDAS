# v0.2.0 — infraestrutura e banco

Branch: release/v0.2.0-database. Firmware permanece em 0.1.1.

Entregues Compose, MariaDB 11.8.8 fixado por digest, importação SQL inicial,
migrações Alembic, API FastAPI, secrets gerados no servidor, healthchecks,
backup/restauração e integração com Traefik existente na rede meshcentral_proxy.
Resolver confirmado letsencrypt, entrypoint websecure.

Usuário comprovou em 08/10/2026 no OCI ARM64: build da API, MariaDB saudável,
SQLs importados, migrate concluído com código 0, API saudável, certificado
Let's Encrypt emitido e curl HTTPS sem bypass retornando {"status":"ready"}.

Correções de implantação: mounts individuais dos hooks/configuração, permissões
dos arquivos públicos e leitura do código pelo usuário sem privilégios da API.

Validação adicional automatizada: recriação de containers preservando volume,
marcador persistente e backup restaurado em MariaDB temporário isolado sem rede.
Comparação integral de dumps determinísticos de schema e dados; recursos
temporários removidos ao terminar. Backup gerado permanece protegido no servidor.
O script recria MariaDB/API e causa breve interrupção; executar sem vendas ativas.

CI inclui Docker/MariaDB reais em AMD64 e ARM64. HTTPS público é verificado no
servidor, não pelo ambiente isolado de CI. Resultado desses testes e da execução
final no OCI ainda pendente; não marcar a etapa aprovada ou criar tag até validar.

Executar: bash docker/scripts/validate-release.sh. Registrar a saída PASS antes
de aprovar a etapa. Schema comercial e assistente/login do Tab5 pertencem às
próximas versões; esta entrega contém a fundação de configuração/RBAC/auditoria.
