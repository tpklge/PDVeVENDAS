# 0.3.1 — Wi-Fi, interface e configurações no microSD (candidata)

Log USB confirmou assert `verify_host_config_for_slave`: rádio C6 detectado,
mas build esperava ESP32. Corrigido `CONFIG_SLAVE_IDF_TARGET_ESP32C6=y` e adicionada
guarda de compilação. Dropdown preservado, pois não causou a falha.

Autoteste de boot usa vetor PBKDF2 de 2.048 iterações; proteção das configurações
mantém 200.000 iterações. Tela inicial imediata, legendas centralizadas,
tema claro, botões cinza com texto escuro. Senha local aceita 4 caracteres,
inclusive PIN de 4 dígitos; senha ERP mantém 20 caracteres.

Todas as configurações locais (SSID, senha Wi-Fi, URL da API, provisionamento e
credencial local criptográfica) ficam em `/ERP/config/settings.enc` no microSD.
NVS não é usada pela aplicação; Wi-Fi usa RAM. Cartão é obrigatório para salvar
ou desbloquear. Gravação temporária sincronizada e cópia `.bak` permitem recuperar
a gravação anterior se faltar o arquivo principal; não há formatação automática.
FAT/cartão continuam sujeitos a corrupção por remoção ou queda de energia.

Para backup, desligar e copiar toda a pasta `ERP` do cartão; guardar a senha local.
Dados do servidor exigem backup MariaDB separado. Migração 0.3.0: refazer a
configuração uma vez; não se lê a NVS antiga. Trocas seguintes preservam o cartão.

Testes de armazenamento cobrem persistência, recuperação entre renames,
falha de I/O, corrupção e reset. Validação física da candidata ainda pendente.
