# 0.4.0 — interface principal (candidata)

Dashboard integrado ao login, menu lateral, tela de sessão/permissões, rede,
troca de senha, bloqueio e logout. Teclado Tab/Shift+Tab e setas navegam, Enter
aciona e Esc retorna ao início no dashboard. Interface 1280x720 em pt-BR.
Tema escuro padrão com texto claro; alternância claro/escuro persistida no
microSD, em ERP/config/theme.bin. Configuração criptografada existente permanece
compatível, sem alterar seu formato. Nenhuma configuração usa NVS.

Wi-Fi usa evento DHCP/desconexão; API é verificada pelo worker a cada 30 segundos.
Requisições, troca de tema e escrita no cartão ocorrem fora da tarefa LVGL.
Sincronização comercial ainda indisponível e indicada explicitamente. Produtos,
clientes, vendas, estoque e relatórios são páginas de navegação preparatórias;
não há operações comerciais, números fictícios ou novos endpoints.

Verificar no Tab5: login abre dashboard; menu funciona por toque e teclado;
rede/senha permitem voltar ao menu; tema persiste após reinício; desconectar
Wi-Fi atualiza indicador sem travar; sessão expirada volta ao login; bloquear
remove tokens/chave; logout revoga a sessão. Aprovação física ainda pendente.

Não é necessário atualizar a API 0.3.2 já instalada. Firmware mantém PIN de
4 caracteres, senha ERP mínima de 8 e reutiliza o microSD existente.
Testes locais: compilação ESP32-P4, 13 testes API, política exata de permissões,
persistência/recuperação de arquivos, cobertura de glifos pt-BR e versões.
