# 0.12.0 — Segurança e estabilidade (candidata em validação)

09/10/2026. Branch release/v0.12.0-security. Etapa 0.11 aprovada pelo usuário.
Esta é a última etapa de implementação antes da homologação/tag 1.0.

## Atualização

Servidor antes do OTA, na raiz da instalação, mesmo sem repositório Git:

```sh
cd /home/ubuntu/TAB5_ERP
unzip -o TAB5_ERP-v0.12.0-server-update.zip
bash docker/scripts/update-security.sh
bash docker/scripts/validate-security.sh
```

Backup antes do build. Recria API 0.12; schema permanece 008_offline. Não altera
usuários, senhas, PIN, Wi-Fi, .env/secrets/volumes ou dados comerciais. Não rodar
initialize, reimportar SQL, apagar NVS/microSD ou gravar via USB.
Depois instale TAB5_ERP-v0.12.0-app-OTA.bin pelo launcher habitual.

## Mudanças e revisão

Autenticação serializa mutações por usuário antes de sessões; revogação concorrente
não permite renovação sobreviver. CLI recebe a senha antes de bloquear a linha.
Auditoria de falhas/limites de login e replay, sem credenciais; cabeçalhos úteis e
falhas genéricas/correlacionadas, sem parâmetros SQL em logs. HTTP limitado a 64 KiB
antes do parsing, inclusive chunked. Relatórios incluem epoch na revisão.

Código do journal v1 extraído para teste sem mudar formato/AAD/chave. Limpeza exige
operador/contexto corretos; arquivo corrompido não é apagado nem substituído por
backup antigo. Erros de acesso impedem trocar PIN/API/reset. Memória temporária é
zerada; falta de memória preserva arquivos e não envia pedido.

Criptografia atualizada para fork oficial Espressif Mbed TLS 3.6.7, SHA-256 fixado,
preparado dentro do build; ESP-IDF compartilhado não muda. CA, hostname, hora, NTP,
DHCP, tempos de espera e PIN continuam como antes. Sem gravar eFuses. Dependências
Python fixadas com hashes; auditoria PyPI datada sem avisos ativos. Docker continua
sem root/portas/capabilities; Traefik envia HSTS no domínio da API.

Ver [segurança](../security.md), [recuperação](../recovery.md),
[sincronização](../synchronization.md) e [desempenho](../performance.md) e [homologação final](../final-validation.md).

persistência/restore, refresh simultâneo e reset com bloqueio, auditoria e 68 testes
API ([CI 37893180005](https://github.com/tpklge/PDVeVENDAS/actions/runs/37893180005)).
Firmware, núcleo portátil, armazenamento real, alocação e TLS aprovados no commit
2244954 ([CI 37892952855](https://github.com/tpklge/PDVeVENDAS/actions/runs/37892952855)).

empacotamento, sem alterar esse código validado.
Esses resultados não equivalem a
ensaio de corrupção física do cartão ou retirada de energia. 0.11 foi aprovada pelo
usuário; firmware 0.12 requer nova confirmação porque a biblioteca TLS mudou.

login; consultar produto e concluir uma venda no caixa; reiniciar e carregar rascunho
