# 0.3.2 — senha ERP simplificada (candidata)

API aceita senha nova de 8 a 128 caracteres, sem exigência de símbolos,
maiúsculas ou números. Senha local permanece em 4 caracteres. CLI no servidor
permite `reset-password --username admin`, solicita nova senha duas vezes sem
exibir, revoga todas as sessões e marca a senha escolhida como definitiva.
Nenhuma mudança de banco ou schema. Sem alteração de configurações no microSD.

Atualizar o código no servidor e reconstruir API antes de usar a nova política:

```sh
cd /home/ubuntu/TAB5_ERP
git fetch origin
git switch release/v0.3.0-authentication
git pull --ff-only
docker compose --env-file docker/.env -f docker/compose.yaml up -d --build --no-deps api
docker compose --env-file docker/.env -f docker/compose.yaml exec api python -m app.cli reset-password --username admin
```

Execute na branch `release/v0.3.0-authentication`; main ainda é a etapa 0.2.0.
A operação solicita senha de forma interativa e preserva usuários e dados.
Escolha 8 ou mais caracteres e entre com `admin` no Tab5. O firmware 0.3.1 já
aceita esse login após reset no servidor; 0.3.2 melhora também a mensagem de erro.

Tema escuro restaurado por solicitação do usuário, com botões cinza-escuros,
texto branco explícito em labels, campos, teclado, mensagens e redes Wi-Fi.
